# Haridas Bargire – Portfolio

React + Vite portfolio.

## Run
    npm install
    npm run dev

## Build
    npm run build

## Where to edit
- Content (text, projects, skills, education): `src/data/portfolio.js`
- Colours and fonts: `:root` in `src/styles/global.css`
- Each section has its own component in `src/components` and its own CSS file in `src/styles`
- Icons: `src/components/Icons.jsx`
- Resume PDF: `public/Haridas_Bargire_Resume.pdf`
